One independent researcher, taking a single question — how should AI actually work alongside people — from lived failure, to methodology, to tools, to shipped products.

What I'm working on

1. AI flatters. It tells you everything you thought was right, and your judgment erodes a little each time (FEE · Flattering-Echo Effect — now quantified).

2. Deep collaboration has no handrail. Long, multi-window, multi-month work drifts quietly. What's missing isn't a stronger model — it's a layer of cognitive calibration.

3. Collaboration is invisible. Nobody can say what actually happened over three months, so nobody can audit it, and nobody can reuse it.

4. One person can't do everything. But teaming up means giving up direction — which is why tools and protocols are the real leverage.

Renpu（仁谱） open source · AGPL-3.0-only

A local relationship-genealogy engine

Whose problemYour phone holds hundreds of contacts, and nobody can say who is connected to whom, or which relationship is real.
What I builtLocal SQLite + six-domain model + relationship-edge inference + read-only WeChat parsing + a 15-subcommand CLI and local API, pure Python with zero compilation — the data never leaves your machine.

SkillBridge in progress

A cross-embodiment Agent skill library

Whose problemThe same robot job skill has to be rewritten for every new machine — the more hardware you mix, the more that repetition costs.
What I builtOne Python Skill that migrates from sim2real to any physical embodiment with zero code changes; 15 ROS2 interface packages compiled clean (140 msg + 93 srv) + a 16-item official capability mapping layer + 15 Skill bindings.
EvidenceGDPS 2026 & IEIC International Embodied Intelligence Skills Competition (Zhangjiang, Shanghai · 2026-10-23—25) · on-device integration was limited by the venue's hardware configuration (missing gateway / battery), so simulation and demo tracks ran in parallel

CrossCheck · Dual-model Reports with On-chain Evidence delivered

Making a report verifiable

Whose problemA report gets produced and nobody can prove it wasn't altered afterwards — especially when AI generated it.
What I builtOff-chain dual-model cross-audit + a SHA-256 canonical hash pinned on chain + a tamper self-check, so the evidence can be recomputed independently. Honest terminology: "match" ≠ "correct"; the chain only proves the result wasn't retroactively rewritten.
Evidencelive demo ↗ · source ↗ (co-owner)
