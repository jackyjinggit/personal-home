同一张图，市场上已有「Before / After：公司层级架构重组」版本（太忆 TiMEM 创始人余宣庆，CCF TF184 分享）。 这张图讲的是同一件事——个人经验如何变成组织资产——但落点不同： 不是把层级拆掉，而是把「谁有权决定方向」这件事从组织里抽出来，交给一个人。

一句话口径：消除的不是层级，是「决策权分散在层级里」； 中层不是被砍，是被重新定义为 协调 / 生产 / 监督 三种权责； 经验不是被收集，是按 个人 → 项目 → 组织 三级沉淀，每级晋升都要过审核门。

读图顺序：顶层是唯一裁决点（方向 / 授权）→ 中层被拆成「协调 / 生产 / 监督」三种权责，各自不可兼任 → 底层的共享技能库把「能力」从编制表挪到基础设施 → 右侧是记忆三级：个人 → 审核门 → 组织，能力再自上而下分发回项目。

与市面那张图的关键差异

维度市面版本（TiMEM）这一版（蒋平）

监督 未出现 独立第三权：反方意见必须出声，可绕过层级直达裁决点
数据主权 未提 图上明写：组织归组织、个人归个人、敏感不上云

三个不画在这张图上、但支撑它的机制

定稿后逐处扩散

组织记忆不是「汇总」，是按序扩散：一处定稿 → 一处一处扩散，每扩散一处先验证一致再进下一处。防止改了一处、其他处还是旧版。这是组织资产能积累而不腐化的关键。

边界护栏

方向终裁之所以能集中在一个人身上而不出问题，靠的是四道闸限定边界：不替决、不自封正解、不可逆须授权、外发须显式。集中权力 + 制度护栏 = 敢集中。

不加修饰与可证伪

输出前默对三条：不附加升华、必须附失效条件（可证伪）、以「能做什么」而非「不能做什么」来定义。让协作质量可被检查，而不是靠感觉。

这张图的诚实边界：它描述的是单人 + 强 AI 协作场景下的组织形态， 不是通用企业模板。若要迁移到几十到几百人的公司，「一人管 N 项目」会撞上真实的管理带宽上限， 「审核门」也会变成组织瓶颈——那时需要的是分层审核与抽样机制，而不是照搬。
