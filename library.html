关于「受限」与「不列」

  • 仁谱 renpu 的完整文档（README / INSTALL / QUICKSTART / SKILL / TROUBLESHOOT）已随本页放出，可直接在线读；但 GitHub 仓库当前对匿名访客不可见——是否公开由你决定。这一条我如实标注，没有把它写成「人人可 clone」。
  • 未收录的，都是还没到可以给人看的时候：仍在进行中的赛事、未公开的论文原稿、内部治理文档与诊断包、涉及他人或第三方的内容。「还没准备好」不等于「做完了但藏着」——前者是状态，后者是判断。
  • 本页所有外链在最近一次核验时均可访问。若你日后调整了任一仓库的公开性，这里需要同步更新标注。
